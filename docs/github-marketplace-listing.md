## Setup Instructions (shown after install)

setup_url: https://codeverify.dev/setup
setup_instructions: |
  ## Quick Start

  1. **Install** the CodeVerify GitHub App from the Marketplace
  2. **Select repositories** to enable verification on
  3. **Open a PR** — CodeVerify will automatically analyze it

  That's it! CodeVerify will:
  - Auto-detect your languages and create `.codeverify.yml`
  - Set up a GitHub Actions workflow for CI integration
  - Run a baseline scan and post your first results

  ### Configuration (optional)

  Create `.codeverify.yml` in your repo root:

  ```yaml
  version: "1"
  languages:
    - python
    - typescript
  verification:
    enabled: true
    checks:
      - null_safety
      - array_bounds
      - integer_overflow
  ai:
    enabled: true
    semantic: true
    security: true
  thresholds:
    critical: 0
    high: 0
    medium: 10
  ```
